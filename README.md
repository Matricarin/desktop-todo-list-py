# desktop-todo-list-py

## описание

Пример CRUD приложения на Python

Микроменеджер задач для рабочего стола.

Поддерживает следующие операции:

* добавить (создать задачу)
* отобразить список задач
* пометить задачу выполненой
* удалить задачу

## реализация

1. реализация методов работы с файлами
2. внедрение методов логирования
3. тестирование разработанных методов

## проблемы

1. Настройки логирования
2. Работа с файлами
